### 安宁医院左右视角切换

- 医院病房现在分为左侧和右侧两个固定视角。
- 玩家可以点击画面两边的箭头切换视角。
- 切换时会先淡出旧画面，再淡入新画面。

### 可拖动的床头柜抽屉

- 床头柜的抽屉现在可以用鼠标或手机手指向下拉出。
- 抽屉里的资料卡可以随着抽屉打开逐渐显示。
- 资料卡只有在抽屉完全打开后才能点击，避免隔着抽屉误触。

### 屏幕适配

- 游戏界面以横屏 `1920 × 1080` 作为设计参考尺寸。
- Canvas 会根据不同手机的屏幕宽度和高度自动缩放界面。
- 场景使用中间 `16:9` 安全内容区，人物、线索和可交互物不会因为超宽屏而跑到危险边缘。
- 背景可以铺满整个屏幕，并在不同屏幕比例下自动裁切边缘，不会把图片强行拉伸变形。
- 已考虑 `16:9`、`16:10`、`19.5:9` 和 `20:9` 等常见横屏比例。
- 物品栏等重要 UI 可以放入手机安全区域，避开刘海、圆角和系统手势区域。
