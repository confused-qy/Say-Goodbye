# 《临终关怀・林姨》游戏流程条件表

> 用途：开发交互逻辑、配置流程条件、制作存档和测试时参考。  
> 原则：游戏进度以“进度标记 + 道具状态”为准，不以某个 GameObject 当前是否显示为准。  
> 注意：心愿三在原流程中为黄色高亮内容，目前属于待修改需求。

## 1. 状态分类

### 1.1 大阶段

| 阶段 ID | 含义 |
| --- | --- |
| `Prologue` | 序章漫画及社工独白 |
| `WishOne` | 心愿一：岁月之歌 |
| `WishTwo` | 心愿二：我的美丽 |
| `WishThree` | 心愿三：好好相见好好告别 |
| `EndingComic` | 结局四格漫画 |
| `Epilogue` | 三个月后空病房尾声 |
| `GameCompleted` | 游戏正式结束 |

### 1.2 道具 ID

| 道具 ID | 中文名称 | 是否建议消耗 |
| --- | --- | --- |
| `PatientInfoCard` | 个人信息卡 | 否 |
| `LifeAlbum` | 生命画册 | 否 |
| `VolunteerList` | 志愿者名单 | 否 |
| `BlankTape` | 空白磁带 | 合成或播放时消耗 |
| `UnfinishedTape` | 未完成磁带 | 播放时可消耗 |
| `RegretFragmentSong` | 遗憾碎片・未完成的歌 | 否 |
| `Cosmetics` | 全套化妆品 | 否 |
| `SmallKey` | 小钥匙 | 打开收纳盒时消耗 |
| `Rouge` | 旧胭脂 | 否 |
| `RegretFragmentLetter` | 遗憾碎片・一封旧日情书 | 否 |
| `Ingredients` | 做饭食材 | 处理和烹饪时消耗，待确认 |
| `RegretFragmentFamily` | 心愿三遗憾碎片 | 否，正式名称待确认 |

## 3. 心愿一：岁月之歌

### 3.1 病房左侧

| 交互/事件 | 前置条件 | 成功结果 | 条件不满足/重复交互 |
| --- | --- | --- | --- |
| 拾取个人信息卡 | 进入心愿一，且未拥有 `PatientInfoCard` | 添加 `PatientInfoCard`；设置 `InfoCardCollected`、`BirthdayDiscovered` | 已拾取则显示已查看内容，不重复添加 |
| 点击上锁资料柜 | `BirthdayDiscovered`，且未设置 `FileCabinetUnlocked` | 打开生日密码输入界面 | 未发现生日则提示“需要一个密码” |
| 输入生日密码 | 密码界面已打开 | 正确：设置 `FileCabinetUnlocked`；错误：显示错误反馈 | 不改变其他剧情状态 |
| 查看生命画册 | `FileCabinetUnlocked` | 添加/记录 `LifeAlbum`；设置 `LifeAlbumRead`、`WishSongDiscovered` | 未解锁资料柜则不可查看 |
| 拾取志愿者名单 | `FileCabinetUnlocked`，且未拥有 `VolunteerList` | 添加 `VolunteerList`；设置 `VolunteerListCollected` | 已拾取则只显示道具详情 |
| 使用名单拨打电话 | 拥有 `VolunteerList`，且未设置 `VolunteerCalled` | 播放通话；设置 `VolunteerCalled` | 无名单则提示“还没有联系方式” |
| 志愿者在门口出现 | `VolunteerCalled` | 设置 `VolunteerArrived`；显示志愿者 | 条件不满足时隐藏志愿者 |
| 点击志愿者 | `VolunteerArrived`，且未完成吉他小游戏 | 播放对话；打开吉他小游戏 | 已完成则播放完成后的简短对话 |

### 3.2 吉他编曲小游戏

| 交互/事件 | 前置条件 | 成功结果 | 失败/退出结果 |
| --- | --- | --- | --- |
| 开始吉他小游戏 | `VolunteerArrived` | 加载音符顺序并允许输入 | 无 |
| 输入错误音符 | 小游戏进行中 | 错误反馈；根据设计重置当前段或允许继续 | 不推进剧情 |
| 完成吉他编曲 | 全部音符正确 | 设置 `GuitarMinigameCompleted`；添加 `BlankTape`；设置 `BlankTapeCollected` | 不重复发放磁带 |
| 退出吉他小游戏 | 尚未完成 | 返回病房，保留或重置小游戏内部进度 | 不设置完成标记 |

### 3.3 病房右侧与回忆

| 交互/事件 | 前置条件 | 成功结果 | 条件不满足/重复交互 |
| --- | --- | --- | --- |
| 将空白磁带放到录音机 | 拥有 `BlankTape`，且 `GuitarMinigameCompleted` | 设置 `HospitalTapePlaced`；录音机变为彩色 | 无磁带则提示需要磁带 |
| 播放录音机 | `HospitalTapePlaced` | 播放林姨对话；设置 `HospitalSongPlayed`；进入客厅回忆 | 已播放则可重复听，但不重复切剧情 |
| 回忆中打开客厅柜子 | 已进入心愿一回忆 | 显示可拾取的空白磁带 | 无 |
| 拾取回忆中的空白磁带 | 未拥有用于合成的 `BlankTape` | 添加 `BlankTape`；设置 `MemoryBlankTapeCollected` | 已拾取则隐藏道具 |
| 查看卧室手写歌词 | 已进入心愿一回忆 | 设置 `LyricsRead`；显示歌词放大界面 | 无 |
| 将空白磁带拖到歌词上 | 拥有 `BlankTape` 且 `LyricsRead` | 移除 `BlankTape`；添加 `UnfinishedTape`；设置 `UnfinishedTapeCreated` | 条件不足则返回道具并显示提示 |
| 将未完成磁带放入播放机 | 拥有 `UnfinishedTape` | 设置 `MemoryTapePlaced`；允许播放 | 无对应磁带则提示 |
| 播放未完成磁带 | `MemoryTapePlaced` | 播放至中途；触发家庭电话；设置 `FamilyPhoneRinging` | 已触发则不重复触发电话 |
| 接听女儿电话 | `FamilyPhoneRinging` | 播放对话；设置 `FamilyPhoneAnswered` | 电话未响时不可接听 |
| 点击闪烁的磁带播放机 | `FamilyPhoneAnswered` | 添加 `RegretFragmentSong`；设置 `FirstWishCompleted` | 已领取则不重复发放 |

## 4. 心愿二：我的美丽

### 4.1 医院化妆心愿

| 交互/事件 | 前置条件 | 成功结果 | 条件不满足/重复交互 |

| 完成全部妆容 | 满足最终确认的化妆完成规则 | 设置 `MakeupCompleted`；播放林姨对话；进入客厅回忆 | 未完成所有必选步骤则提示继续 |

### 4.2 向日葵与旧物

| 交互/事件 | 前置条件 | 成功结果 | 条件不满足/重复交互 |
| --- | --- | --- | --- |
| 点击向日葵盆栽 | `MakeupCompleted`，且未完成向日葵谜题 | 打开向日葵小游戏 | 已完成则显示全部盛开状态 |
| 点击一朵向日葵 | 小游戏进行中 | 切换自身及左右相邻花朵状态 | 不推进剧情，直到全部盛开 |

## 6. 结局与尾声

| 交互/事件 | 前置条件 | 成功结果 | 条件不满足/重复交互 |
| --- | --- | --- | --- |
| 解锁结局 | `FirstWishCompleted`、`SecondWishCompleted`、`ThirdWishCompleted` | 进入 `EndingComic` | 任一心愿未完成则不开放 |
| 播放结局四格漫画 | 进入 `EndingComic` | 依次展示和解、拥抱、拍照、全新全家福；设置 `EndingComicViewed` | 已观看时可允许回看 |
| 进入三个月后病房 | `EndingComicViewed` | 进入 `Epilogue`；显示空病床和录音笔 | 无 |
| 点击录音笔 | 进入 `Epilogue` | 播放完整录音；设置 `FinalRecordingPlayed` | 播放中禁止重复启动音频 |
| 完成游戏 | `FinalRecordingPlayed` 且录音播放结束 | 进入 `GameCompleted`；保存通关状态；显示结束界面 | 录音未结束时不触发 |

## 7. 通用交互规则

| 情况 | 统一处理建议 |
| --- | --- |
| 条件不足 | 显示具体提示，不静默失败，例如“还不知道密码” |
| 重复领取道具 | 不重复添加，只显示道具详情或“已经拿过了” |
| 错误道具拖拽 | 道具返回物品栏，不消耗，不推进剧情 |
| 小游戏退出 | 不设置完成标记；是否保留内部进度由各小游戏决定 |
| 淡入淡出期间 | 禁止场景和导航按钮接收新的触摸事件 |
| 切换视角 | 不改变剧情和物品栏状态，只刷新当前视角表现 |
| 读取存档 | 根据进度标记恢复物体状态，不依赖上次 GameObject 的 Active 状态 |
| 触摸交互 | 使用 `Button.onClick` 或 EventSystem 指针接口，不依赖鼠标悬停、右键 |

## 8. 推荐存档内容

```text
SaveData
├── CurrentChapter
├── ProgressFlags
├── InventoryItems
├── CurrentHospitalView
├── CompletedMinigames
├── ViewedDialogues
├── MusicVolume
└── SoundVolume
```

存档时机建议：

- 获得或消耗关键道具后。
- 完成小游戏后。
- 设置心愿完成标记后。
- 进入回忆、结局或尾声时。
- 游戏退到后台时（微信小游戏需要单独测试生命周期回调）。

## 9. 实现检查原则

开发每个交互物前，至少明确以下五项：

1. 玩家点击/拖拽的对象是什么？
2. 它要求哪些进度标记或道具？
3. 条件不足时显示什么？
4. 成功后增加、移除或设置什么？
5. 读取存档后，它应该显示成什么状态？
